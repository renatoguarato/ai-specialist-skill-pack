# Specialized roles for Devin CLI

These are **role instructions**, not a claim that Devin CLI auto-registers subagents from this folder. Supply the relevant role when delegating a bounded task, using CLI-supported subagent capabilities.

- `architecture-reviewer.md`: system boundaries, ADRs, tradeoffs and migration.
- `python-engineer.md`: Python/FastAPI implementation and tests.
- `ai-systems-engineer.md`: LangChain/LangGraph, RAG, tools and evaluations.
- `security-reviewer.md`: threats, authorization, PII, OWASP and IAM.
- `test-engineer.md`: test design, regression and contract coverage.
- `devops-engineer.md`: ECS, pipelines, telemetry and rollback.

Each role must follow `AGENTS.md` and return evidence, uncertainty, risks and a bounded handoff. Delegate independent tasks only, and avoid passing unnecessary private data.
