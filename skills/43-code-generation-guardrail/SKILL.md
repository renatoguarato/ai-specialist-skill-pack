# Code Generation Guardrail

## Antes de editar
- entender arquitetura;
- localizar testes;
- avaliar impacto;
- confirmar contratos;
- identificar convenções.

## Durante
- alterações pequenas;
- evitar refactor não solicitado;
- preservar compatibilidade;
- não remover segurança;
- não inventar APIs.

## Depois
- executar testes;
- analisar diff;
- validar lint/build;
- revisar segurança;
- documentar riscos.
