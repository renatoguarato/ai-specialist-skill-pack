# AI System Discovery

## Objetivo
Criar uma visão factual de como a aplicação usa IA.

## Procure
- modelos utilizados;
- provedores;
- prompts;
- system prompts;
- tool calling;
- agents;
- planners;
- routers;
- RAG;
- embeddings;
- vector stores;
- rerankers;
- memória;
- guardrails;
- avaliações;
- observabilidade;
- caching;
- fallback de modelo;
- controle de custos.

## Workflow
1. Identifique todos os pontos onde modelos são invocados.
2. Relacione cada chamada ao caso de uso.
3. Identifique prompts e templates.
4. Identifique fontes de contexto.
5. Identifique ferramentas e permissões.
6. Identifique armazenamento de conversas/memória.
7. Identifique mecanismos de avaliação.
8. Identifique mecanismos de segurança.
9. Identifique dependências externas.
10. Identifique riscos operacionais.
