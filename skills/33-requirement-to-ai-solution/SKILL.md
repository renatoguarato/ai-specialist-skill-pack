# Requirement to AI Solution

## Objetivo
Evitar começar pelo modelo antes de entender o problema.

## Workflow
1. Identifique o problema real.
2. Defina resultado esperado.
3. Identifique usuários e decisão suportada.
4. Liste dados disponíveis.
5. Determine se IA é necessária.
6. Compare:
   - regra determinística;
   - busca;
   - workflow;
   - ML tradicional;
   - LLM;
   - RAG;
   - agente.
7. Avalie riscos, custo, latência e explicabilidade.
8. Proponha uma solução mínima.
