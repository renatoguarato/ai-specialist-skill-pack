# Implementation Planner

## Objetivo
Planejar antes de editar código.

## Regras
- Preserve convenções existentes quando adequadas.
- Evite introduzir novo framework sem necessidade.
- Destaque decisões irreversíveis.
- Prefira pequenos increments.
- Inclua estratégia de rollback.
