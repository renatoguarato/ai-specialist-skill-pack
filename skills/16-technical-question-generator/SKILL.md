# Technical Question Generator

## Objetivo
Preparar perguntas para devs, arquitetos, PO, SRE e especialistas de domínio.

## Regras
Não pergunte algo facilmente verificável no repositório.

Priorize:
- contexto histórico;
- decisões e trade-offs;
- exceções de negócio;
- incidentes passados;
- dependências críticas;
- ownership;
- riscos conhecidos;
- restrições regulatórias;
- dívida técnica;
- roadmap.

## Saída
Agrupe perguntas por:
- Negócio;
- Arquitetura;
- Operação;
- Segurança;
- Dados;
- Delivery.

Para cada pergunta, informe por que ela é importante.
