# AI POC Designer

## Objetivo
Evitar POCs que apenas demonstram que uma API funciona.

## Workflow
1. Defina hipótese.
2. Defina baseline atual.
3. Defina problema mensurável.
4. Crie dataset representativo.
5. Defina variantes.
6. Defina métricas.
7. Defina limite de custo e tempo.
8. Defina critério GO/NO-GO.

## Saída
### Hypothesis
### Baseline
### Scope
### Dataset
### Experiment Matrix
### Metrics
### Acceptance Criteria
### Cost Bound
### Decision Rule
