# LLM Evaluation Designer

## Objetivo
Transformar qualidade subjetiva em critérios mensuráveis.

## Avaliações possíveis
- correctness;
- relevance;
- faithfulness;
- groundedness;
- completeness;
- safety;
- tone;
- structured output accuracy;
- tool selection;
- task completion;
- latency;
- token cost.

## Workflow
1. Defina comportamento esperado.
2. Crie dataset representativo.
3. Inclua casos normais e adversariais.
4. Defina métricas.
5. Defina baseline.
6. Defina threshold.
7. Automatize quando possível.
8. Separe avaliação offline e online.
