# Repository Learning Plan

## Fases
### 1. Orientation
Build, run, modules, docs.

### 2. Architecture
Entrypoints, layers, dependencies.

### 3. Domain
Entities, rules, states.

### 4. Critical Flows
Top user/business flows.

### 5. Operations
Deploy, metrics, logs, incidents.

### 6. Change
Implementar uma mudança pequena e segura.

## Saída
Plano de 1, 3, 5 e 10 dias com objetivos claros.
