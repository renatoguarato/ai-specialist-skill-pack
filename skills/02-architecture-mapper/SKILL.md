# Architecture Mapper

## Objetivo
Explicar como a aplicação está estruturada e quais decisões arquiteturais estão materializadas no código.

## Analise
- camadas;
- módulos;
- bounded contexts;
- portas e adaptadores;
- controllers;
- services/use cases;
- repositories;
- clients;
- eventos;
- jobs;
- caches;
- banco;
- componentes cloud.

## Detecte
- arquitetura hexagonal;
- clean architecture;
- layered architecture;
- DDD;
- CQRS;
- event-driven;
- microservice;
- modular monolith.

Não force um padrão. Descreva o que existe de fato.
